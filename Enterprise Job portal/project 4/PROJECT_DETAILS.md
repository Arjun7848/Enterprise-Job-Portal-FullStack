# 🚀 Enterprise Job Portal - Project 4

Welcome to the **Industry-Level Job Portal**! This is a complete, full-stack application designed to rival platforms like LinkedIn, Internshala, and Indeed. It features a futuristic **Glassmorphism UI**, real-time interactions, and AI-driven candidate tools.

---

## 🛠️ Required Software to Install
Before running the project, ensure you have the following installed on your system:
1.  **Node.js (LTS Version):** [Download here](https://nodejs.org/) (This includes `npm`).
2.  **Code Editor:** [Visual Studio Code](https://code.visualstudio.com/) is highly recommended.
3.  **A Web Browser:** Chrome, Edge, or Brave (for Voice Search support).

---

## 🏃 How to Run the Project
Follow these steps to get the platform live on your local machine:

1.  **Open your Terminal/Command Prompt.**
2.  **Navigate to the project root folder:**
    ```bash
    cd "project 4"
    ```
3.  **Install all dependencies (Frontend + Backend + Root):**
    ```bash
    npm run install:all
    ```
    *(This may take a few minutes as it installs React, Express, Framer Motion, Socket.io, etc.)*
4.  **Start the development server:**
    ```bash
    npm start
    ```
5.  **Access the application:**
    -   **Frontend:** [http://localhost:5173](http://localhost:5173)
    -   **Backend API:** [http://localhost:5000](http://localhost:5000)

## 🌟 Key Features Implemented
The project consists of 17+ fully integrated modules:

1.  **Recruitment Suite:** Post jobs, search with **Voice Search**, and track applications.
2.  **AI Smart Matching:** Automatically scores jobs based on your profile skills.
3.  **ATS Resume Checker:** Analyze your resume against job descriptions for compatibility.
4.  **Real-Time Chat:** Direct instant messaging between recruiters and candidates via Socket.io.
5.  **Elite Resume Studio:** Build a professional profile and link **Video Introductions**.
6.  **Learning Hub:** Explore and enroll in career-focused certifications and courses.
7.  **Company Hub:** Research employer culture and read authentic employee reviews.
8.  **Admin Terminal:** Full system governance, user moderation, and health analytics.
9.  **Notification Center:** Real-time in-app alerts for interview invites and status updates.
10. **Monetization:** Subscription tiers (Free/Pro/Enterprise) with simulated payment flows.
